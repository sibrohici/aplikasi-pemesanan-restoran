# aplikasi-pemesanan-restoran

Aplikasi pemesanan restoran sederhana berbasis Java yang dibuat untuk mempelajari dasar-dasar pemrograman Java, pengelolaan data menu, pemrosesan pesanan, dan perhitungan transaksi.

## Fitur

- Menampilkan daftar menu makanan dan minuman.
- Memasukkan pesanan berdasarkan nama menu dan jumlah porsi.
- Memvalidasi nama menu dan jumlah pesanan.
- Menghitung subtotal pesanan.
- Menghitung pajak sebesar 10%.
- Menambahkan biaya layanan sebesar Rp8.000.
- Memberikan promo gratis satu minuman dengan syarat tertentu.
- Memberikan diskon 10% jika subtotal lebih dari Rp100.000.
- Menghitung total pembayaran, kembalian, atau kekurangan pembayaran.

## Teknologi

- Java
- Java Development Kit (JDK)
- Java Scanner
- Array dan Method
- Class dan Object

## Cara Menjalankan

1. Pastikan Java JDK sudah terinstal.
2. Buka terminal pada folder proyek.
3. Masuk ke direktori `src`.
4. Kompilasi program:

```bash
javac Main.java Menu.java
```

5. Jalankan program:

```bash
java Main
```

## Format Input Pesanan

Gunakan format:

```text
Nama Menu = Jumlah
```

Contoh:

```text
Nasi Padang = 2
Es Teh = 2
```

Proyek ini dibuat sebagai bagian dari proses pembelajaran pemrograman Java dan pengembangan kemampuan dalam membuat aplikasi sederhana berbasis console.
